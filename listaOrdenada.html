Passo a passo para fazer um café

  1. Ferver a água
  2. Colocar o pó de café no filtro
  3. Despejar a agua quente no filtro
  4. Fechar a garrafa termica

Marcadores dos itens de list (li)

  • type = 1: Números padrão(1, 2, 3, ...)
  • type = A: Letras maiúscula(A, B, C, ...)
  • type = a: Letras minúscula(a, b, c, ...)
  • type = I: Algarismos romanos maiúscula(I, II, III, ...)
  • type = i: Algarismos romanos minúscula(i, ii, iii, ...)

Modo de preparo de bolo

  1. Pré-aquecer o forno a 180°
  2. Untar a forma com margarina e farinha de trigo
  3. Bater/misturar os ingredientes
  4. Adicionar a farinha e misturar levemente
  5. Acrescente o chocolate em pó
  6. Acrescente uma colher de sopa de fermento em pó
  7. Despeje a massa na forma
  8. Asse de 35 a 40 minutos em 180°
